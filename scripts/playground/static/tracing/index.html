A kids' app on imajev

Trace it.
imajev checks it.

A child traces the dotted letter with a finger and taps Check. A star if it is right, a friendly nudge if not.

  1. imajev reads what was written, from the strokes alone. It never sees the dotted guide and is not told the answer, so it cannot be fooled by either.
  2. The app checks every line was traced: how much of each dotted line the strokes pass over. Plain geometry, done on the device.
  3. Both must agree for a star. A wrong letter gets named (“That looks like an H!”).

Checked on generated sample tracings, not on real children's handwriting: check run. Drawings go only to the local imajev server; only stars are kept.

imajev-4b · about 0.45 s per check on a Mac Studio.
